## 修复：UI 只能导入 CSV 的问题

- 根因：①主导入按钮只走 `useCSVImport.handleImportCSV`（accept=.csv，Electron filters 也只列 CSV）；②Excel 导入藏在无文字的表格图标二级对话框；③决定性 bug——`ExcelDialog` 原 `if (!isOpen || !project || !layout) return null`，无项目时整窗空白（layout 只在 project 存在时初始化），导致必须先导 CSV 才能用 Excel。
- 修复：`useCSVImport` 改为统一入口 `handleImport`，按扩展名路由 csv/xlsx/xls；Web `<input accept=".csv,.xlsx,.xls">`、Electron 按后缀造 File；xlsx 走 `importGanttWorkbook`+`loadProject`（保留旧资源表），含在线行数上限判断。保留 `handleImportCSV` 别名兼容快捷键。
- `ExcelDialog`：useEffect 无 project 时用 DEFAULT_EXCEL_LAYOUT 初始化 layout；去掉 `!project` 提前返回；导入写回全用 `project?.`；无项目时禁用导出按钮。
- `electron/main.ts`：openFile filters 加 CSV/Excel 合并项。i18n 五语言补 `toolbar.importFile`、`error.unsupportedFile`。
- 验证：tsc 通过；27 项测试全过；web/electron 双构建通过。注意示例 55 行 > 在线版 50 行上限，须用桌面版导入（已写入 examples/README.md）。
- 文档 SECONDARY_DEV_GUIDE.md 增补统一导入入口与 ExcelDialog 修复说明。

## 修复：桌面版导入 xlsx 报 Corrupted zip

- 现象：`Excel 导入失败：End of data reached (data length = 74271, asked index = 122842). Corrupted zip?`
- 根因：Electron `fs:readFile` 固定 `readFile(path,'utf-8')` 返回字符串；CSV 正常，但 xlsx 是 zip 二进制，UTF-8 解码损坏后交给 ExcelJS 必然报损坏。
- 修复：`electron/main.ts` 新增 `fs:readFileBinary`（Buffer→base64），`preload.ts` 暴露 `readFileBinary`；`useCSVImport` 按扩展名选通道，Excel 用 base64→Uint8Array→File，CSV 仍走文本；`src/lib/binary.ts` 封装 `base64ToBytes`；openFile filters 改为 xlsx/xlsm。
- 验证：新增回归测试「imports a workbook transferred through the Electron base64 bridge」，tsc 干净、28 项测试全过；重新生成 dist 与 dist-electron，桥接函数已确认进入产物。
- 注意：正在运行的旧进程需重启后才生效；若使用安装包，需重新打包。

## 新增：固定周期单/多周期视图（用户选 B：展开多周期实例，且要求单/多周期都能展示）

- 设计原则：底层永远只存一份**动作模板**；多周期是只读投影，不是复制数据。编辑任一实例通过 `templateIdOf` 回写模板，所有周期同步，避免回到重复编辑老路。
- 数据：`CycleConfig { enabled, cycleMs, repeats }`（ProjectData 增补）；ModuleData 增补 `cycleIndex` / `cycleTemplateId`（仅实例有）。schemaVersion 仍为 2，旧项目默认单周期。
- 引擎 `src/lib/cycleEngine.ts`：`expandCycles` 生成 `@Cn` 实例（时刻平移 `(n-1)*cycleMs`，复制 parentId/predecessors/allocations），`collapseCycleProjection` 折叠回模板；超周期告警。
- 派生视图 `src/hooks/useCycleView.ts`：甘特/资源泳道/Excel 共用同一份展开→排程→占用结果。
- UI：GanttView 工具栏「单周期/多周期」分段切换 + 齿轮 `CycleDialog`（周期时长/周期数/预设/超周期提示）；甘特画紫色周期分隔线与 C1/C2 编号，行标签带 C 角标；实例双击编辑映射到模板。折叠模板行会隐藏其全部实例。
- 资源：跨周期重叠由现有 `resourceScheduler` 在实例占用上直接检出（测试证明单周期 0 冲突、2 周期检出 500ms 冲突）。
- Excel：设置表写入 cycleEnabled/cycleMs/cycleRepeats；导出当前可见周期视图；导入折叠 @Cn 行回模板并按配置重建。`useCSVImport`/ExcelDialog 回写 cycleConfig。
- 边界：经典节拍网格、PDF、MP4 仍按单周期模板输出（避免 N 倍行塞进动画），已写入设计文档。
- 验证：tsc 干净；36 项测试全过（新增周期引擎 7 项 + Excel 多周期往返 1 项）；五语言补 cycle 文案；SECONDARY_DEV_GUIDE.md 增补 2.1 节与改造清单。
