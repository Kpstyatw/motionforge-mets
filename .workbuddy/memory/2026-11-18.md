## 新需求：甘特矩阵表头时间合并

- 需求：可设置间隔 N 个刻度，把甘特矩阵表头每 N 个时间列合并成一个单元格，显示该段时间（如 0ms–400ms），解决窄列时间标签竖排拥挤。
- 实现：

  - 设置写入「设置与依赖」表 key `matrixLabelEvery` 并读回，往返无损。
  - `ExcelDialog` 加输入框 + 说明；五语言补 `matrixLabelEvery`/`matrixLabelEveryHint` 文案。
- 验证：真实示例 149 列→37 合并块（D1:G1 等），标签 0ms–1200ms/1200ms–2400ms，数据行 0 合并。全量 45 项测试通过（原 44 + 新 1），tsc 干净，Electron/在线双构建通过，产物含 matrixLabelEvery。

## 修复：Electron 桌面版无法新建资源（window.prompt 被禁用）

- 现象：用户反馈"好像无法新建资源"。store 层 `addResource` 复现测试正常（能加进去），说明不是逻辑问题。
- 根因：`ResourceAllocationDialog.quickAddResource` 用 `window.prompt()` 输入资源名。**Electron 不支持 `window.prompt`（静默返回 null、不弹窗）**，Web 浏览器正常——所以同一份代码 Web 版能建、桌面版点了没反应。这正是"别的电脑能用"的原因（浏览器版）。
  - 注：`window.confirm`（TaskEditorDialog 删除确认）Electron 是支持的，无需改。
- 修复：改为应用内内联输入框——资源下拉框旁「新建」按钮切换显隐一个 input（placeholder 复用 `resource.newName`），回车或点「添加」调用 `addResource` 并自动选中；新增 state `quickName`/`quickAdding`。
- 验证：tsc 干净，49 项测试全过；重新 `npm run build:web`（→dist-web）与 `npx vite build`（→dist 桌面版），dist 产物 `window.prompt` 命中 0、含内联输入特征；桌面版启动正常（App focused）。
- 经验：**Electron 里避免用 window.prompt**（alert/confirm 可用，prompt 不行）；涉及文本输入一律用应用内 UI。

## 新增：一键保存（Ctrl+S 存回原 Excel / 另存为）

- 需求：导入 Excel 编辑后能直接保存，不必每次走「导出→手动覆盖」。原先只有导出，`unsavedChanges` 只是状态位无自动保存。
- 实现链路：
  - store 加 `sourceFile: {path?,name,kind}|null` + `setSourceFile`；`loadProject` 不清（保留导入关联），`createNewProject`/`clearProject` 清空。
  - 主进程加 `fs:writeFileBinary`（base64→Buffer→writeFile），preload 暴露+声明类型；`src/lib/binary.ts` 加 `bytesToBase64`（与读取方向 `base64ToBytes` 对称）。**写 xlsx 必须走二进制通道，utf-8 会损坏 zip（与之前导入踩的坑同源）**。
  - `src/services/saveProject.ts`：buildGanttWorkbook 生成 Blob → 桌面端有 sourceFile.path 直接写回（Ctrl+S），无路径或另存为弹 `saveFile` 对话框；Web 端走 downloadBlob。
  - `src/hooks/useSaveProject.ts`：封装 useCycleView + flattenTree，调 saveProjectExcel，toast 成功/失败，写回后更新 sourceFile 并 `setUnsavedChanges(false)`。
  - 导入来源记录在 `useCSVImport`（工具栏文件对话框有绝对路径）与 `ExcelDialog`（隐藏 input 仅名称）。
  - `shortcuts.ts` 加 `save`(Ctrl+S)/`save-as`(Ctrl+Shift+S) 命令 → 自动进原生菜单、快捷键、帮助对话框；App.tsx commands 表接线 + 工具栏加 FaSave 按钮。
  - 五语言补 `menu.file.save/saveAs` 与顶层 `save.ok/failed/empty`。
- 验证：tsc 干净；50 项测试全过（新增 sourceFile 生命周期回归 1 项）；`npx vite build`（桌面，含 main.js+preload.js+renderer）与 `npm run build:web` 双构建通过，产物含 writeFileBinary 与保存特征；桌面版启动正常。
- Web 版限制：浏览器无法覆盖本地文件，Ctrl+S 一律下载新文件；在线版行数上限 50 行仍适用。
