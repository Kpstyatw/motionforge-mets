# 2026-11-20 工作日志

## 新增 NSIS 安装包打包脚本

- 新增 `build-installer.bat`：与 `build-portable.bat` 同结构的一键安装包打包脚本。
  - 复用 package.json `build.nsis.artifactName`：`DYNMECH-CycleView-Setup-<version>.exe`。
  - 核心命令：`npx electron-builder --win nsis -c.electronDist=<local> -c.directories.output=release-build/installer-<TS>`。
  - 支持 `nocheck` / `nopause` 参数；输出从临时时间戳目录复制到 `release/` 后删除临时目录。
  - 临时目录前缀与便携版区分（`installer-<TS>` vs `<TS>`），避免清理时误删。
- 验证：`npx electron-builder --win nsis` 成功，产出 `DYNMECH-CycleView-Setup-1.0.3.exe`（97 MB，oneClick=false/perMachine=false/允许改安装目录），已复制到 `release/`。NSIS 工具链已缓存，可离线打包。
- 注意：直接双击 bat 需在 Windows 资源管理器中执行；工具侧禁用 cmd.exe 调用，故用等价原生命令验证。
