## v1.1.0：资源占用绑定动作事件 + 归属改资源侧（一对多）

- **事件锚定占用**：`ResourceAllocation` 新增 `bindMode:'manual'|'event'`、`startRef/endRef:{taskId,at:'start'|'end',offsetMs?}`。event 模式窗口 = `[事件时刻(startRef), 事件时刻(endRef))`，起止可指向不同动作（抓手A开始占用→C结束释放）。`resourceScheduler.resolveEventTime` 从实时排程取时刻，级联自动跟随；引用删除/窗口逆序降级无效并进 `resourceSchedule.warnings`。多周期 ref 的 taskId 同步映射 `@Cn`。冲突检测两种模式共用绝对窗口，仍只提示不改时序。`ResourceAllocationDialog` 加手动/绑定模式切换 + 动作/事件点/偏移选择 + 实时窗口预览 + 占用编辑（✎）。
- **归属改资源侧**：`Resource.ownerNodeId`（一个机构可归属多个资源，解决原 `ModuleData.resourceId` 单值互斥 bug）。`buildResourceOwnerIndex(modules, resources)` 资源侧优先/节点侧兜底；所有调用点（useCycleView/ResourceManagerDialog/excelService/pdfExport）已传 resources。`setResourceOwner` 只改资源侧不动兄弟；`linkMechanismResource` 兼容镜像。`migrateProject` 把旧 `module.resourceId` 迁移为 ownerNodeId。Excel 资源表加"归属节点ID"列（第12列）。
- Excel 占用表扩为 18 列（新增绑定模式/起止动作编号/事件点/微调）；导入按 code→id 映射事件动作。JSON/CSV 走完整快照自动带新字段。
- 5 语言补文案 + `common.edit/save`。测试 123 项全通过；typecheck/vite build/build:web 通过。
- 版本 1.0.3 → 1.1.0；产物 `release/DYNMECH-CycleView-Portable-1.1.0.exe`（80M）、`release/DYNMECH-CycleView-Setup-1.1.0.exe`（97M）。

## v1.1.1：动作 ↔ 子动作时间关联（相对时间模型）

- 用户选择三项：改父动作子动作跟随、子动作必须落在父窗口内、子动作起始相对父动作计算。
- **数据模型**：`ModuleData.offsetFromParentMs?`（子动作相对最近祖先动作起始的偏移，动作/汇总行不用）。`migrateProject` 的 `deriveSubActionOffsets` 为旧子动作按父绝对 start 反推偏移，并清除指向祖先的旧依赖（避免与相对模型冲突）。新建子动作 / `setTaskTiming` 写相对偏移。
- **调度器核心**（`computeSchedule` Pass 1.5 + 1.6，在依赖排程后、rollup 前）：Pass 1.5 按树序解析 `sub.start = 祖先动作resolvedStart + offset`（嵌套链式），改父动作或依赖级联时子树跟随；前置任务作为硬下限（max）。Pass 1.6 把含子节点的 action/subaction 时长扩到覆盖子树最终边界，排在依赖约束之后，修复「父动作 auto + 前置时被拉回、子戳出父窗口」旧 bug。
- **setTaskTiming 不再用 autoExpandParentTimes 写回**（它会用陈旧子树时间把编辑中的父 start 拉回）：改为 commit 前用 `computeSchedule` 预演，仅生成准确的「父已扩展」提示 changes。`autoExpandParentTimes` 函数保留（仅测试用）。
- **三格式**：Excel 动作表新增「相对父偏移 (ms)」列（col offsetFromParentMs，导入回写）；JSON/CSV 走快照自动带。`cycleEngine` 用 `...m` 展开自动保留该字段（同周期父子一起平移，偏移不变）。
- 编辑框：子动作「开始/结束」显示并输入相对偏移（label 改「开始偏移/结束偏移」+ 蓝色说明），动作仍绝对。5 语言补 `gantt.subRelativeHint/startOffset/endOffset`。
- 测试 134 项全过（新增依赖引擎 6 条 + store 4 条 + Excel 往返 1 条；旧 rollup 测试改用 offset 构造）。typecheck/vite build/build:web 通过。
