## 前置任务候选：允许选择无血缘的父动作（低风险方案）

用户反馈：编辑父动作（容器 action/subaction）时，可选前置任务比编辑子动作少，且"其它层级"的选项也偏少。根因是旧候选过滤 `candidate.isLeaf` 把容器一刀切排除，而 `wouldCreateHierarchyConflict` 又排除了当前节点的整棵子树。

采用的低风险方案（不改排程引擎）：
- `src/lib/dependencyEngine.ts` 新增 `resolvePredecessorLeaf(schedule, candidateId): string | null`：叶子返回自身；容器返回其子树中 `endMs` 最大的叶子（= "整组完成后"）。依赖只写入该叶子 id，避开容器 rollup 时间过期问题。
- `src/components/TaskEditorDialog.tsx` 候选过滤改为：叶子 + 无血缘的 action/subaction 容器；仍排除 module/mechanism 汇总、祖先/后代血缘、会成环、已添加项（按换算后的 fromId 去重）。提交时用换算后的 fromId 调 `addPredecessor`。容器选项带"（整组完成后）"标签。
- 祖先/后代互为前置的硬约束保持不变（child-driven 模型的 rollup 环）。

验证：typecheck、全量测试（154 passed）、vite build、build:web 全部通过。

## Pass 1.7 修复：容器后继未收到刷新后的前置约束

用户实测：项目 `D:\work history\层浪\cenglang\2500动作时序.json` 中 03.01.03（容器）前置为 03.01.06.04（03.01.06 子树叶子），但 03.01.03 没有从 03.01.06 结束(20000)开始，停在 7500。

根因：Pass 1.5 按 containersDeepFirst 顺序定位容器，03.01.03 排在 03.01.06 前面，算约束时 03.01.06.04 还没被自身容器平移，用的是旧 end(4500) → 判定已满足不动。Pass 1.7 原本 `if (containerIds.has(id)) return` 跳过容器，只给叶子后继传播平移，所以容器后继永远保留过期约束。

修复（`src/lib/dependencyEngine.ts` Pass 1.7）：去掉容器跳过；对容器后继用最新前置时间重算 floor（FF/SF 用其 rollup span），若 floor > 子树起点则整棵子树平移一个 delta 并重算 rollup，纳入重复 sweep 收敛。前置仍是硬下限，已满足则不动。

## Pass 1.8 修复：auto 叶子被整组平移拖出 stale gap

用户实测：03.01.03.02（auto，前置 03.01.03.01 + 02.02.03）起始 28500，离最晚前置结束 21000 有 7500 空档，不合理。用户明确规则：没有额外前置/时间偏移时，auto 子动作应贴着两个前置的最后结束时间。

根因：Pass 1 用前置**原始**时间给 auto 叶子算 start（03.01.03.02=16000）；随后父容器因自身前置整组平移 +12500，所有子孙无差别 +12500 → 28500。但前置 03.01.03.01 移到 21000、外部前置 02.02.03 只到 16500，正确贴合点应是 21000。Pass 1.7 只做"往后推"的硬下限（21000 < 28500 不动），gap 永久保留。

修复（`src/lib/dependencyEngine.ts` 新增 Pass 1.8，在 Pass 1.7 之后）：对所有 `startMode==='auto'` 且有前置的**叶子**，用最终前置时间重算 constraintFor 并直接把 startMs 贴合到该 floor；clamp 到所有祖先容器 constraintMs 最大值以防把叶子拉到早于容器前置下限；sweep 迭代收敛后 recomputeRollup。`manual` 叶子、无前置叶子、cyclic 节点、容器本身都不动——保留原 authored 位置（只有 Pass 1.7 的硬下限约束）。lag/SS/FF/SF 经 constraintFor 自然保留。

真实项目复核：03.01.03.02 = 21000-22500（贴 03.01.03.01 end），对 02.02.03 的 4500 间隔是"等最晚前置"的正常结果；整棵子树变紧凑链式（03.01.03 结束 32500 → 25000）。

验证：typecheck、全量测试（162 passed，新增 2 条：auto 贴合 + manual 不贴合）、vite build、build:web 全部通过。
