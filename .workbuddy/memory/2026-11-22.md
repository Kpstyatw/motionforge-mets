# 2026-11-22 工作日志

## 前置任务候选：允许选择无血缘的父动作（低风险方案）

用户反馈：编辑父动作（容器 action/subaction）时，可选前置任务比编辑子动作少，且"其它层级"的选项也偏少。根因是旧候选过滤 `candidate.isLeaf` 把容器一刀切排除，而 `wouldCreateHierarchyConflict` 又排除了当前节点的整棵子树。

采用的低风险方案（不改排程引擎）：
- `src/lib/dependencyEngine.ts` 新增 `resolvePredecessorLeaf(schedule, candidateId): string | null`：叶子返回自身；容器返回其子树中 `endMs` 最大的叶子（= "整组完成后"）。依赖只写入该叶子 id，避开容器 rollup 时间过期问题。
- `src/components/TaskEditorDialog.tsx` 候选过滤改为：叶子 + 无血缘的 action/subaction 容器；仍排除 module/mechanism 汇总、祖先/后代血缘、会成环、已添加项（按换算后的 fromId 去重）。提交时用换算后的 fromId 调 `addPredecessor`。容器选项带"（整组完成后）"标签。
- 祖先/后代互为前置的硬约束保持不变（child-driven 模型的 rollup 环）。

验证：typecheck、全量测试（154 passed）、vite build、build:web 全部通过。

注：`release/` 下便携 exe 仍是旧版，源码改动需重新打包才会进入 exe。
