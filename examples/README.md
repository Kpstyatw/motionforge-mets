# 示例：化学发光免疫分析仪 · 单次检测流程

一份可直接导入 CycleView 甘特版的工作样例，建模对象为**磁珠法化学发光免疫分析仪（CLIA）**从样本进样到结果上传的完整单测试周期。数据用整数毫秒表达，时间轴压缩为约 44.4 秒（真实温育为分钟级，此处压缩以便在一屏内观察）。

## 文件

| 文件 | 用途 |
|---|---|
| `化学发光免疫分析仪-动作时序甘特.xlsx` | **主交付**。五工作表（动作时序 / 甘特矩阵 / 设置与依赖 / 资源 / 资源占用），在工具里「Excel → 导入 Excel」即可原样导回，时序精确到 1ms 无损。 |
| `化学发光免疫分析仪-项目数据.json` | 完整 `ProjectData` 快照，供二次开发对照数据结构、或程序化加载。 |

## 如何体验

1. 打开工具 → 点工具栏最左的**导入按钮**（向上箭头），现在它同时接受 `.csv` 与 `.xlsx`，按扩展名自动路由；或在「甘特」视图点表格图标打开 Excel 对话框点「导入 Excel」。两种方式都能在**还没有任何项目**时直接用 Excel 作为首个导入（无需先导入 CSV）。
   - 注意：本例 55 行，超过**在线预览版的 50 行上限**，请用**桌面版（Electron）**导入；桌面版无行数限制。
2. 工具栏点「**资源**」切换到资源泳道视图：11 条资源泳道，其中**管库抓手**泳道有 2 处红色重叠块（下面详述）。
3. 回到「流程」视图，找到带红色角标的动作 `S06 / S07`，双击 `S06` 把持续时长从 900ms 改成 1500ms → 所有后置动作（S07→S09→…→S26）起始时间自动级联顺延；切回资源视图，抓手冲突区间同步变化。
4. 「时间刻度」里把精度改成 10ms 再改回 1ms，观察所有时刻按新精度重新量化。

## 层级结构（模块 → 机构 → 动作 → 子动作 → 子子动作）

```
M1 样本处理模块
 ├ 样本针组件 → 样本针吸样与加样
 │    ├ S01 样本针下降 → S02 吸样30µL → S03 抬升转位
 ├ 管库抓手组件 → 抓取反应杯承接加样
 │    ├ S04 抓手移动至管库 → S05 抓取空反应杯 → S06 移送反应杯 → S07 保持承接
 └ 扫码组件 → 样本条码识别 → S08 样本管旋转扫码
M2 反应温育模块
 ├ 试剂针1组件 → 加磁珠包被抗体 → S09吸试剂 → S10加试剂 → S11洗针
 ├ 试剂针2组件 → 加吖啶酯标记抗体 → S12吸试剂 → S13加试剂 → S14洗针
 └ 温育盘组件 → 37°C温育 → S15转入 → S16温育20s → └ S17间歇转动(嵌套子子动作)
M3 分离洗涤模块
 ├ 磁分离组件 → 磁珠分离 → S18转入 → S19磁场捕获
 └ 洗涤组件 → 三阶洗涤 → S20加清洗液 → S21吸废液 → └ S21A废液泵排液(嵌套)
M4 发光检测模块
 ├ 底物针组件 → 加激发底物 → S22预激发液(H₂O₂) → S23激发液(NaOH)
 └ PMT检测组件 → 发光检测 → S24送暗室 → S25采集RLU(400ms) → S26浓度换算
M5 样本稀释模块(分支流程)
 └ 稀释抓手复用 → 丢弃稀释完成反应杯 → S27 抓手丢弃稀释管
```

共 55 个节点（含 4 个模块、10 个机构、以及含嵌套的子动作）。

## 依赖链（考察级联重算）

主链为 FS（完成→开始）串联，穿插两条 SS（开始→开始）与一处 +100ms 延迟：

```
S01 ─FS→ S02 ─FS→ S03
S04 ─FS→ S05 ─FS→ S06 ─FS→ S07 ─FS→ S09(+0) ─FS→ S10 ─FS→ S11 ─FS(+100)→ S12 ─FS→ S13 ─FS→ S14 ─FS→ S15 ─FS→ S16 ─FS→ S18 ─FS→ S19 ─FS→ S20 ─FS→ S21 ─FS→ S22 ─FS→ S23 ─FS→ S24 ─FS→ S25 ─FS→ S26
                                                                      S16 ─SS(+1000)→ S17
                                                                      S21 ─SS(+0)→ S21A
```

## 资源冲突（本例刻意内置，用于演示资源视图价值）

**管库抓手（RES-TUBE-GRIPPER）** 被两个不同流程复用：

- `S06` 移送反应杯至加样位：`1700–2600ms`
- `S07` 保持承接样本臂加样：`2600–4500ms`
- `S27` 稀释分支——抓手丢弃稀释完成的反应管：`2000–3600ms`

冲突检测结果（半开区间 `[start,end)`）：

| 资源 | 冲突动作 | 重叠 |
|---|---|---|
| 管库抓手 | S06 × S27 | 600ms（2000–2600） |
| 管库抓手 | S27 × S07 | 1000ms（2600–3600） |

这正是「流程视角看不出、资源视角一眼可见」的典型：S27 属于 M5 稀释分支，在流程树里与 M1 的 S06/S07 相隔很远；按资源投影到同一泳道后争用立即暴露。工具当前**只提示不自动消解**，红标与角标供排程人员决策。

另含两处「精确窗口」示范：`S02` 动作本身 800–2300ms，但样本针只在 1000–1900ms 吸液段被占用（offset=200, duration=900）；`S07` 同一动作同时占用抓手与加样位载具，体现多对多协同。
